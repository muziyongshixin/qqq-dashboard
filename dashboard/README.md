# QQQ-RP 策略监控看板

多资产动量 × 风险平价 × 波动率目标策略的每日监控看板。
纯静态页面（GitHub Pages 托管）+ GitHub Actions 每日自动更新数据。

## 功能

| 模块 | 说明 |
|---|---|
| **本周调仓动作** | 目标权重、与上期对比的买入/加仓/减仓/清仓、按本金换算的下单金额（本金可在页面上改） |
| **净值曲线与回撤** | 日频净值 + 沪深300 基准对比 + 回撤序列，两图时间轴联动；支持近1月/3月/6月/1年/3年/全部切换 |
| **滚动区间指标** | 近 1/3/6/12 月 + 今年以来 + 全样本：收益、最大回撤、夏普、Sortino、Calmar、年化波动、日胜率 |
| **逐年收益 / 最长水下期** | 逐自然年收益分布；水下期分段（含"零亏损年份为何仍有长水下期"的解释） |
| **调仓历史** | 最近 60 期的选中只数、事前波动、缩放系数、风险仓位、换手率、持仓明细 |

## 数据源

**tdxrs 0.6.7（通达信直连）为唯一权威源** —— 使用官方除权除息数据（`get_fund_xdxr_info`）
做精确前复权，历史最长（最早 2011-09）、无 HTTP 限流。

> ⚠ tdxrs 硬要求 **Python ≥ 3.11**（只提供 cp311 wheel，其余是 Rust 源码包需编译链）。
> 工作流中已固定 `python-version: '3.11'`，**不要降级**。

### 除权事件监控 → 增量 / 全量自动切换

每次运行先取全部标的的除权除息信息（14 次请求约 1s，很便宜），据此决定走哪条路：

| 检查项 | 结果 | 动作 |
|---|---|---|
| 除权指纹 vs 上次 | **有变动** | 🔴 全量重建 |
| 增量窗口内是否含除权日 | **含** | 🔴 全量重建 |
| 快照是否有指纹（旧版产出） | **无** | 🔴 全量重建并补齐 |
| 上述全部通过 | — | 🟢 **增量更新** |
| 增量后重叠段逐点校验 | **偏差 >1bp** | 🔴 放弃增量、转全量 |

实测效果（14 只标的，本机）：

| 模式 | 请求 K 线 | 耗时 |
|---|---|---|
| 全量重建 | 38,686 根 | 5.5s |
| **增量更新** | **126~168 根（0.33%~0.43%）** | **2.3s** |
| 无新交易日（周末/盘中） | 0 根 | 1.0s |

**增量结果已逐点验证与全量重建完全一致：38,686 个点，最大偏差 0.000000 bp。**

#### 为什么必须监控除权事件

前复权的定义是「把除权日**之前**的所有历史价格整条改写」。所以只要出现一个新的
分红/拆股事件，旧基线的**每一根**历史 K 线都失效了 —— 此时把新几天接到末尾会得到
一条前后比例不一致的曲线，而且**看不出明显异常**（跳变已被复权抹平），
非常危险。所以宁可多做几次全量。

#### 两个判据为什么都需要

指纹只能发现「除权事件列表变了」。但还有一种情况指纹发现不了：
事件**上次就已存在**（指纹相同），可是增量窗口恰好横跨了这个除权日 ——
窗口内复权比例不恒定，按单一锚点外推同样会拼错。

> 实测踩到过：512480 半导体 ETF 于 **2026-07-03 拆股 1:2**（`suogu=2.0`）。
> 窗口内 k 值在除权日前是 0.5、之后是 1.0，极差 100%。
> 当时靠第三道保险（重叠段逐点校验，报 5000bp 偏差）拦下，随后补上了判据②。

#### 增量窗口为什么要自适应

窗口若固定 60 根（≈3 个月），511010 / 511260 国债 ETF **每季度分红**，
几乎任何时候回溯 60 根都会横跨一个分红日 → 判据② 常年成立 → 增量形同废纸。

所以窗口按 **「缺失天数 + 3 根重叠」** 自适应收缩，通常只有 4~12 根，
横跨除权日的概率大幅下降；即便真横跨了，也只在那一天全量，之后立刻恢复增量。

### 降级链（tdxrs 不可用时的安全网，正常不会触发）

1. tdxrs 增量 / 全量 → 数据质量最高
2. 东财 HTTP → 新浪 HTTP 增量补齐 —— **按收益率拼接**，不用绝对价格
   （各家前复权基准日不同，绝对价位不可比，但日收益率可比；
   按比例外推可避免在拼接点产生虚假跳变）
3. 两者都失败 → 保留上次快照并标记 `stale`，页面顶部显著提示「数据未更新」

**任何一只标的增量失败都不会写入**，避免各标的时间轴不齐导致权重失真。

## 本地预览

```bash
cd dashboard

# 首次：生成权威价格基线（需 Python 3.11 + tdxrs）
python3 tools/fetch_prices.py --full

# 计算指标与调仓信号
python3 tools/build_dashboard.py

# 起服务预览（必须走 HTTP，直接双击 HTML 会因 CORS 无法读取 JSON）
python3 -m http.server 8901
# → http://localhost:8901/
```

日常只需 `python3 tools/fetch_prices.py && python3 tools/build_dashboard.py`
（自动判断增量/全量）。

常用参数：

| 参数 | 说明 |
|---|---|
| `--full` | 强制全量重建（怀疑数据有问题时用） |
| `--tail N` | 增量窗口上限根数（默认 60，一般不用改） |
| `--no-http` | 禁用 HTTP 降级：tdxrs 不可用则保留旧快照 |

## 部署到 GitHub Pages

```bash
# 1. 在仓库根目录初始化并推送
git init && git add -A
git commit -m "feat: QQQ-RP 策略监控看板"
git branch -M main
git remote add origin git@github.com:<你的用户名>/<仓库名>.git
git push -u origin main
```

2. 仓库 **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**
3. 仓库 **Settings → Actions → General → Workflow permissions** 选
   **Read and write permissions**（Actions 需要提交更新后的数据文件）
4. 到 **Actions** 页手动跑一次 `每日更新策略看板` 验证
5. 之后每个交易日 **北京时间 16:10** 自动更新（18:10 补跑一次容错）

页面地址：`https://<你的用户名>.github.io/<仓库名>/`

> 若仓库根目录还有其他内容，Pages 只会发布 `dashboard/` 目录
> （工作流里 `upload-pages-artifact` 的 `path: dashboard`）。

## 策略参数（理论常数，不做网格搜索）

| 参数 | 值 | 依据 |
|---|---|---|
| 动量窗口 | 4/8/13/26/52 周等权 | Moskowitz-Ooi-Pedersen (2012)；刻意不挑最优子集 |
| 入选阈值 | 窗口上涨占比 > 0.5 | 5 窗至少 3 窗上涨 |
| EWMA λ | 0.94，**作用于日收益 ×252** | RiskMetrics (1996) 原文即日频（半衰期约 11 个交易日） |
| 目标波动 | 10% 年化 | Moreira & Muir (2017) |
| 债券上限 | 35% | 久期集中度风控；敏感性测试支持 30~35% |
| 最小持仓 | 2% | 避免给宽价差品种（原油 18bp）开碎仓 |
| 杠杆 | 无 | 国内融资成本约 6%，会吃掉全部夏普增益 |
| 最短历史 | 53 周 | = 最长回看窗口 + 1；严格无前视 |

### 两处易错的时钟设置（勿改回）

- **风险时钟 = 日频**：λ=0.94 用在**周**收益上，半衰期会变成约 11 周，危机时降仓过慢。
  改日频后实测：夏普 1.332→1.415、MDD -13.22%→-11.40%。信号仍按周决策，两个时钟分离。
- **预热时钟 = 上市以来真实历史**：从回测起点重新数 53 周会让首年整体空仓。
  用起点**之前**的已发生数据预热**不是前视**。该项贡献 +0.114 夏普。

### 现金腿必须用 511880

不要用 511990 华宝添益：它是"份额结转型"货币基金，场内价恒约 100 元，
收益体现在份额增长而非价格，用其价格序列回测必然得到零收益。
511880 银华日利是价格累积型（年化约 2.53%）。

## ⚠ 关于指标的重要说明

**夏普口径**：本看板用 `(CAGR − 2%) / 年化波动`（日收益 ×√252）。
聚宽平台用 `(年化 − 4%) / (日收益std × √250)` —— 本策略波动 8~9% 时，
**聚宽夏普约比本看板低 0.28**。跨平台对比时务必注意。

**回测指标含约 0.5 夏普的资产池事后选择偏差**：把这 13 只换成同大类的其他 ETF
（大类分布完全一致），夏普从 1.22 掉到 0.65。这部分是"回看时已知哪些标的表现好"
带来的，**不可复制**。

> **实盘合理预期：夏普 0.7~1.0、年化 7~10%、最大回撤 -15%~-18%。**
> 看板上的历史指标验证的是"实现是否正确"，不是"未来能赚多少"。

本项目为个人量化研究记录，**不构成任何投资建议**。
